# Moose 2.4000 thread test corpus

This directory contains the unchanged upstream thread-specific TODO test from
Moose 2.4000. The source archive is
`ETHER/Moose-2.4000.tar.gz` from CPAN; the test's SHA-256 is recorded by the
thread ecosystem source check.

The TODO is part of the upstream compatibility result and must not be rewritten
as a PerlOnJava-specific pass or skip.

# Archive

Documents kept for reference only. They describe work that is finished,
superseded, or abandoned, and they are not maintained: paths, commands, and
status statements inside them may be out of date.

| Directory | Contents |
|---|---|
| [design/](design/) | Completed plans, handoffs, dated batch notes, and single-issue or single-PR investigations moved out of `dev/design/` |
| [prompts/](prompts/README.md) | Analyses and LLM prompt files from before the project adopted `.agents/skills/` |

For current behavior read [`dev/architecture/`](../architecture/README.md).
For active plans read [`dev/design/`](../design/README.md).

Do not link to an archived document as the authority for current behavior. If
an archived document still contains a decision that matters, copy that
decision into the relevant architecture document. Nothing here may be a
dependency of the build or of a test gate.
